    Radio administration

    Radio DTMF control

    Checking

    Use a private radio password to change recording, spoken status, or automatic identification.

    How to use the radio menu

    Enter the six-character DTMF password, press # and release PTT. Choose 0 to hear current settings. To change a setting, choose 1 for status announcements, 2 for recording, or 3 for automatic station identification, then 0 for off or 1 for on. Press # and release PTT after each choice, then wait for the prompt. Use * to cancel. Each prompt gives you 30 seconds of idle time after it finishes. A valid option starts a fresh window; a completed action needs the password again. Recording commands affect the current session; the startup preference stays unchanged.

    Spoken responses use SvxLink’s transmitter. Receive-only mode (TX=NONE) cannot broadcast responses. This switch does not enable a transmitter.

    Admin sign-in and a configured private code are required.

    Add the current channel-pair number and recording state after a successful change. Menu prompts and the basic confirmation always play.

    Change DTMF password

    Use exactly six characters: 0–9, uppercase A–D. Use # to submit and * to cancel over the radio. The new password is visible while you enter it and is cleared after submission. It is stored privately on the Pi and never returned. Changing it ends any open radio menu.
